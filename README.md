# منصة المدرسة — نقطة البداية

ده المستودع اللي فيه كل اللي محتاجه عشان تبدأ بناء منصة المدرسة التعليمية.

## الملفات
- **`build-brief.md`** — الموجز الكامل: الأدوار والصلاحيات، الجداول، التقنية المقترحة، الهوية البصرية، وخطة التنفيذ من 12 مرحلة.
- **`code-mode-first-message.md`** — أول رسالة تبعتها لـ Code mode عشان يبدأ صح.
- **`index.html`** — الصفحة العامة (عربي/إنجليزي) بشكلها النهائي، وهي المرجع البصري لكل الصفحات الجاية.
- **`assets/logo.svg`** — اللوجو (شمس + خلايا شمسية + قوس طاقة أخضر).
- **`assets/hero.jpg`** — صورة الواجهة.

## تشغيل الصفحة العامة
مفيش أي تثبيت مطلوب، الصفحة HTML واحدة:

```bash
python3 -m http.server 3000
```

وبعدين افتح `http://localhost:3000`. التبديل بين عربي/إنجليزي من زر ع/EN فوق.

## البدء في البناء
اقرأ `build-brief.md` الأول، وابدأ بالمرحلة 0 ثم المرحلة 1 بس، وبعدين وقّف واستنى الموافقة.
