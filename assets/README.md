# مجلد الأصول

- **logo.svg** — لوجو المدرسة (شمس + خلايا شمسية + قوس طاقة أخضر). جاهز للاستخدام.
- **hero.jpg** — مش موجود هنا. صورة الواجهة ملف صورة (binary) والرفع بتاعها مكنش مضمون، وهي متاحة في الملف المضغوط school-platform-start.zip اللي في الشات الأصلي.

## المطلوب
حط ملف اسمه hero.jpg جوه المجلد ده، أو ولّد صورة جديدة بنفس الفكرة (ألواح شمسية وقت الغروب، ألوان دافية، تكوين بسيط) وسمّيها بنفس الاسم.

الصفحة index.html بتستدعي assets/hero.jpg وبتديها aspect-ratio: 16/11، فأي صورة بنفس النسبة هتظبط من غير أي تعديل في الكود.
