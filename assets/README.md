# مجلد الأصول

- **`logo.svg`** — لوجو المدرسة (شمس + خلايا شمسية + قوس طاقة أخضر). جاهز للاستخدام.
- **`hero.jpg`** — **مش موجود هنا.** صورة واجهة المدرسة ملف صورة (ثنائي) وملحقتش تتنقل للمستودع، وهي متاحة في الملحق `school-platform-start.zip` في الشات الأصلي.

## إيه المطلوب منك
حط ملف اسمه `hero.jpg` في المجلد ده، أو ولّد صورة جديدة بنفس الفكرة (ألواح شمسية وقت الغروب، ألوان دافية، بسيطة) وسمّيها نفس الاسم工作人员的. الصفحة `index.html` بتستدعي `assets/hero.jpg` وبتديها `aspect-ratio: 16/11`.
